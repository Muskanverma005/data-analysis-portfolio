# 📊 Mobile Sales Data Analysis Dashboard | Power BI

## 🚀 Project Overview

This project focuses on analyzing mobile sales data using **Microsoft Power BI** to create an interactive dashboard that provides meaningful business insights.

The dashboard helps understand sales performance, customer behavior, payment preferences, and mobile model trends through interactive visualizations and KPIs.

## 🎯 Project Objectives

* Analyze overall mobile sales performance.
* Identify top-performing mobile models.
* Understand city-wise sales distribution.
* Track monthly sales quantity trends.
* Analyze customer payment preferences.
* Evaluate customer ratings and purchasing patterns.

## 📌 Dashboard Highlights

The dashboard includes the following key insights:

**1. Key Performance Indicators (KPIs)**

* Total Sales
* Total Quantity Sold
* Total Transactions
* Average Sales

**2. Sales Analysis**

* Total Sales by City using Map Visualization.
* Total Quantity by Month.
* Sales Performance by Mobile Model.
* Total Sales by Day Name.

**3. Customer & Payment Analysis**

* Transactions by Payment Method.
* Customer Ratings Analysis.
* Comparison of customer purchasing patterns.

## 🛠️ Tools & Technologies Used

* Microsoft Power BI
* Data Visualization
* Interactive Slicers & Filters
* Business Intelligence
* Data Analysis

## 🎛️ Dashboard Interactivity

The dashboard includes interactive filters that allow users to explore the data dynamically:

* Month-wise filtering (January–December).
* Mobile Model filtering.
* Dynamic visual updates based on selected filters.
